# Trilha de Python - DIO 🐍

Este repositório tem como finalidade demonstrar os conhecimentos adquiridos durante a **Trilha de Python** oferecida pela [DIO] (https://www.dio.me/).

## 📂 Estrutura do Projeto

- **Fundamentos:** conceitos básicos de Python (variáveis, funções, estruturas, tipos, etc).
- **Projetos:** pequenos projetos práticos aplicando os conhecimentos.
- **Desafios:** exercícios e desafios da trilha.

## 🧑‍💻 Tecnologias utilizadas
- Python 3.x
- VS Code
- Git & GitHub
